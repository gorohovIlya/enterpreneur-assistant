# Enterpreneur Assistant

Ваш персональный помощник в выборе организационно-правовой формы предприятия.

## Быстрый запуск (Docker)

Убедитесь, что на вашем компьютере установлены [Git](https://git-scm.com) и [Docker](https://docker.com).

1. Клонируйте репозиторий и перейдите в папку проекта:
   ```bash
   git clone https://github.com/gorohovIlya/enterpreneur-assistant.git
   cd enterpreneur_assistant
   ```

2. Соберите и запустите контейнеры в фоновом режиме:
   ```bash
   docker compose up -d --build
   ```

3. Откройте приложение в браузере по адресу: **http://localhost**

Для остановки проекта выполните:
```bash
docker compose down
```

## Как происходит подбор ОПФ

Подбор реализован как детерминированный алгоритм на клиенте (без «чёрного ящика»): результат полностью определяется ответами пользователя и набором правил в коде.

**Ключевые файлы реализации:**
- [`frontend/src/app/services/recommendation.ts`](frontend/src/app/services/recommendation.ts) — правила отбора, расчёт баллов, выбор альтернатив и формирование причин.
- [`frontend/src/app/data/opf-catalog.ts`](frontend/src/app/data/opf-catalog.ts) — справочник форм (описание, плюсы, ограничения, налоги, ответственность, число учредителей).
- [`frontend/src/app/models/opf.ts`](frontend/src/app/models/opf.ts) — типы входных данных и результата.
- [`frontend/src/app/pages/recommend/recommend.ts`](frontend/src/app/pages/recommend/recommend.ts) — форма из 6 вопросов и значения, которые передаются в алгоритм.

### Входные данные (6 вопросов)

| Вопрос | Поле | Значения |
|---|---|---|
| Сколько будет учредителей? | `founders` | `one` — один; `couple` — 2–4; `group` — 5–50; `many` — 51 и больше |
| Планируемая годовая выручка | `revenue` | `micro` — до 2,4 млн ₽; `small` — от 2,4 до 60 млн ₽; `large` — свыше 60 млн ₽ |
| Планируете нанимать сотрудников? | `employees` | `true` / `false` |
| Планируете привлекать внешних инвесторов? | `investors` | `true` / `false` |
| Нужна ли ограниченная ответственность? | `limitedLiability` | `true` / `false` |
| Что важнее на старте? | `priority` | `simplicity` — простая регистрация и отчётность; `scaling` — масштабирование и привлечение капитала |

> Примечания: порог 2,4 млн ₽ используется как ориентир на лимит дохода для НПД; граница 60 млн ₽ — продуктовая эвристика для разделения сценариев, а не прямой законодательный порог.

### Алгоритм

1. Для каждой из 5 форм (НПД, ИП, ООО, АО, ПК) проверяются **жёсткие условия допустимости**.
2. Формы, не прошедшие условия, исключаются из рассмотрения.
3. Для допустимых форм считается числовой **балл** (сумма базового значения и модификаторов по ответам).
4. Кандидаты сортируются по убыванию балла. При равенстве сохраняется исходный порядок перебора: НПД → ИП → ООО → АО → ПК.
5. **Лучшая форма** — первый кандидат в отсортированном списке. Если допустимых кандидатов нет, по умолчанию выбирается ООО.
6. **Альтернативы** — до 2 следующих форм с баллом `> 0` (не совпадающих с рекомендованной).
7. **Причины** (`reasons`) формируются отдельной логикой на основе выбранной формы и ответов; они поясняют результат, но не влияют на баллы.

Дополнительный ИИ-ответ (если запрошен пользователем через `/api/ai`) строится отдельно и **не изменяет** основную rule-based рекомендацию.

### Жёсткие условия и правила начисления баллов

#### НПД (самозанятый, налог на профессиональный доход)

**Условия допустимости (все одновременно):**
- `founders = one`
- `employees = false`
- `revenue = micro` (до 2,4 млн ₽/год)
- `investors = false`

Если условия не выполнены — форма не рассматривается.

**Баллы:** база `10`
| Условие | Изменение |
|---|---|
| Нужна ограниченная ответственность (`limitedLiability = true`) | `-12` |
| Ограниченная ответственность не нужна | `+2` |
| Приоритет — простота (`priority = simplicity`) | `+3` |
| Приоритет — масштабирование | `-1` |

#### ИП (индивидуальный предприниматель)

**Условия допустимости:** `founders = one` (иначе не рассматривается).

**Баллы:** база `6`
| Условие | Изменение |
|---|---|
| `revenue = small` | `+3` |
| `revenue = micro` или `large` | `+1` |
| Планируются сотрудники | `+1` |
| Планируются инвесторы | `-3` |
| Нужна ограниченная ответственность | `-4` |
| Приоритет — простота | `+2` |

#### ООО (общество с ограниченной ответственностью)

**Условия допустимости:** нет (всегда рассматривается).

**Баллы:** база `5`
| Условие | Изменение |
|---|---|
| `founders = one` | `+1` |
| `founders = couple` или `group` (2–50) | `+3` |
| `founders = many` (51+) | `-2` |
| `revenue = micro` | `+1` |
| `revenue = small` или `large` | `+3` |
| Планируются сотрудники | `+1` |
| Планируются инвесторы | `+3` |
| Нужна ограниченная ответственность | `+4` |
| Приоритет — масштабирование | `+2` |
| Приоритет — простота | `+1` |

#### АО (акционерное общество)

**Условия допустимости:** нет (всегда рассматривается).

**Баллы:** база `2`
| Условие | Изменение |
|---|---|
| `founders = many` (51+) | `+8` |
| `founders = couple` или `group` (2–50) | `-1` |
| `founders = one` | `-3` |
| `revenue = large` | `+5` |
| `revenue = small` | `0` |
| `revenue = micro` | `-3` |
| Планируются сотрудники | `+1` |
| Планируются инвесторы | `+3` |
| Нужна ограниченная ответственность | `+2` |
| Приоритет — масштабирование | `+3` |
| Приоритет — простота | `-4` |

#### ПК (производственный кооператив)

**Условия допустимости (все одновременно):**
- `founders = group` (5–50 участников)
- `investors = false`
- `limitedLiability = false`

Если условия не выполнены — форма не рассматривается.

**Баллы:** база `2`
| Условие | Изменение |
|---|---|
| `revenue = large` | `-2` |
| `revenue = micro` или `small` | `+2` |
| Планируются сотрудники | `+1` |
| Приоритет — простота | `+2` |
| Приоритет — масштабирование | `-3` |
| Бонус: выручка не `large` **и** приоритет — простота | `+5` |

### Примеры расчёта

**Пример 1 — НПД**  
Вход: 1 учредитель, выручка до 2,4 млн ₽, без сотрудников, без инвесторов, ограниченная ответственность не нужна, приоритет — простота.  
- НПД допустим: `10 + 2 (без огранич. отв.) + 3 (простота) = 15`  
- ИП допустим: `6 + 1 (micro) + 0 + 0 + 0 + 2 = 9`  
- ООО допустим: `5 + 1 (one) + 1 (micro) + 0 + 0 + 0 + 1 = 8`  
**Результат:** НПД.

**Пример 2 — ИП**  
Вход: 1 учредитель, выручка 2,4–60 млн ₽, сотрудники есть, без инвесторов, ограниченная ответственность не нужна, приоритет — простота.  
- НПД недопустим (есть сотрудники и выручка выше лимита).  
- ИП: `6 + 3 (small) + 1 (сотрудники) + 0 + 0 + 2 = 12`  
- ООО: `5 + 1 (one) + 3 (small) + 1 + 0 + 0 + 1 = 11`  
**Результат:** ИП.

**Пример 3 — ООО**  
Вход: 2–4 учредителя, выручка 2,4–60 млн ₽, сотрудники есть, инвесторы есть, нужна ограниченная ответственность, приоритет — масштабирование.  
- ООО: `5 + 3 (couple) + 3 (small) + 1 + 3 + 4 + 2 = 21`  
- АО: `2 - 1 (2–50) + 0 (small) + 1 + 3 + 2 + 3 = 10`  
**Результат:** ООО.

**Пример 4 — АО**  
Вход: 51+ учредителей, выручка свыше 60 млн ₽, сотрудники есть, инвесторы есть, нужна ограниченная ответственность, приоритет — масштабирование.  
- АО: `2 + 8 (many) + 5 (large) + 1 + 3 + 2 + 3 = 24`  
- ООО: `5 - 2 (many) + 3 (large) + 1 + 3 + 4 + 2 = 16`  
**Результат:** АО.

## Правовая основа (законы РФ)

Подбор опирается на общие положения законодательства РФ об организационно-правовых формах, статусе предпринимателей и налоговых режимах. Ниже — основные нормативные акты и нормы, отражённые в правилах и справочнике сервиса.

| Форма / аспект | Нормативный акт | Ключевые положения, учтённые в сервисе |
|---|---|---|
| НПД (самозанятый) | Федеральный закон от 27.11.2018 № 422-ФЗ «О проведении эксперимента по установлению специального налогового режима "Налог на профессиональный доход"» | Спецрежим для физлиц/ИП без наёмных работников; лимит дохода 2,4 млн ₽ в год; ставки 4% (доходы от физлиц) и 6% (от юрлиц/ИП); ограничения по видам деятельности и перепродаже (ст. 4, 6, 10 422-ФЗ) |
| ИП | Гражданский кодекс РФ (ст. 23, 24); Федеральный закон от 08.08.2001 № 129-ФЗ «О государственной регистрации юридических лиц и индивидуальных предпринимателей» | ИП — физлицо, зарегистрированное для предпринимательской деятельности; отвечает по обязательствам всем своим имуществом; простая регистрация и возможность применять спецрежимы |
| ООО | Гражданский кодекс РФ (ст. 66, 87–94); Федеральный закон от 08.02.1998 № 14-ФЗ «Об обществах с ограниченной ответственностью» | 1–50 участников; уставный капитал не менее 10 000 ₽; участники не отвечают по обязательствам общества и несут риск убытков в пределах стоимости вкладов/долей (ст. 3, 7, 14 14-ФЗ) |
| АО | Гражданский кодекс РФ (ст. 96–104); Федеральный закон от 26.12.1995 № 208-ФЗ «Об акционерных обществах» | Уставный капитал разделён на акции; акционеры не отвечают по обязательствам общества и несут риск убытков в пределах принадлежащих акций; публичные и непубличные общества, корпоративные процедуры и реестр акционеров (ст. 2, 3, 7 208-ФЗ) |
| Производственный кооператив | Гражданский кодекс РФ (ст. 106.1–106.6); Федеральный закон от 08.05.1996 № 41-ФЗ «О производственных кооперативах» | Добровольное объединение граждан для совместной деятельности на основе личного трудового/иного участия; не менее 5 членов; члены несут по обязательствам кооператива субсидиарную ответственность в предусмотренном уставом размере (ст. 1, 4, 7, 13 41-ФЗ) |
| Налоговые режимы | Налоговый кодекс РФ: гл. 26.2 (УСН), гл. 26.5 (ПСН), гл. 21, 23, 25 (элементы ОСНО) | В справочнике форм указаны типовые режимы (НПД, УСН, патент, ОСНО) с учётом их применимости и ограничений |

### Важные юридические уточнения

- **НПД** — специальный налоговый режим, а не отдельная организационно-правовая форма юридического лица; в интерфейсе он включён в список вариантов для удобства выбора.
- **ИП** — статус физического лица, а не юридическое лицо.
- Для **непубличного АО** число акционеров ограничено (50); если акционеров становится больше, общество подлежит преобразованию в публичное. Сценарий «51+» в сервисе трактуется как случай, ориентированный на публичную/крупную акционерную структуру.
- Классификация субъектов МСП регулируется Федеральным законом от 24.07.2007 № 209-ФЗ, однако числовые пороги выручки в анкете сервиса являются упрощённой эвристикой и не совпадают напрямую с критериями МСП.

## Дисклеймер

- Рекомендация носит информационный характер и **не является юридической, налоговой или бухгалтерской консультацией**.
- Правила начисления баллов, пороги и веса — эвристика сервиса для первичной ориентации, а не нормы права.
- Законодательство и правоприменительная практика могут изменяться. Перед регистрацией бизнеса и выбором режима налогообложения проверяйте актуальные редакции законов и при необходимости консультируйтесь со специалистом.
